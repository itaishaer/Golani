# כלי ההדרכה — בא"ח גולני

מרכז הכלים של בסיס האימונים של חטיבת גולני. אפליקציית רשת שאפשר להתקין על מסך הבית.

**כתובת:** https://itaishaer.github.io/Golani/

## הוספה או עריכה של כלי

1. פותחים את `index.html` ולוחצים על סמל העיפרון.
2. מחפשים `const TOOLS = [`. כל שורה ברשימה היא כלי אחד.
3. מעתיקים שורה קיימת ומעדכנים בה:
   - `name`: שם הכלי
   - `cat`: קטגוריה, אחת מהרשימה `CATS` שמתחת
   - `url`: הקישור לכלי (השאירו `""` כדי להציג "בקרוב")
   - `desc`: תיאור קצר
   - `art`: איור, אחד מ: target, calendar, topo, shield, squad, checklist, flag, exam, catalog, compass
   - `tone`: צבע, אחד מ: olive, earth, mustard, sand, rust, moss
   - `featured:true`: אם הכלי צריך להופיע בכרטיסים הגדולים למעלה
4. שומרים עם **Commit changes**.
5. ב-`sw.js` מעלים את המספר ב-`VERSION` באחד (למשל `v1` ל-`v2`), כדי שהעדכון יגיע גם למי שכבר התקין.

השינוי מופיע באתר תוך דקה או שתיים.

## חשוב

המאגר ציבורי, וכל מי שיש לו את הכתובת רואה את התוכן. שמים כאן רק שמות של כלים וקישורים, בלי פרטים אישיים ובלי מידע מסווג.
